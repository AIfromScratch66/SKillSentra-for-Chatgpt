# SkillSentra brand source

- `skillsentra-logo-source-v2.jpg` is the latest user-provided master artwork received on 2026-08-20.
- `skillsentra-logo.png` is the lossless PNG conversion of that full master artwork.
- `demo-apple/skillsentra-logo.png` is the production PNG with only excess outer whitespace removed. Its logo geometry, wordmark, tagline, colors, and shading are unchanged.
- `demo-apple/skillsentra-logo-transparent.png` removes only that production PNG's flat matte. It preserves the existing mark, wordmark, tagline, proportions, colors, highlights, and shadows.
- `demo-apple/skillsentra-icon.png` is the square, transparent, text-free image logo derived from the user-supplied artwork for browser tabs and in-page icon positions.
- Marketplace and control-plane wordmark positions continue to use the full transparent logo. Browser tabs and mark-only UI positions use `demo-apple/skillsentra-icon.png`.

Do not replace the three-arc geometry or change the wordmark spelling without a brand review.
