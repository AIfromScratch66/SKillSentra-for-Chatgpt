# SKillSentra for Chatgpt 0.8.0

Released as a public source edition derived from SkillSentra Personal, with the Personal edition's existing source-visible, all-rights-reserved licensing posture.

## Highlights

- Dedicated display name `SKillSentra for Chatgpt` and machine identity `skillsentra-for-chatgpt`.
- A stateless JSON-response MCP-over-HTTP adapter that reuses the existing 19-tool catalog and execution layer.
- Loopback-first defaults, bounded requests, Origin checks, separate gateway and service credentials, and explicit confirmation for state-changing tools.
- A portable plugin builder and deterministic release pipeline with an SBOM, hashes, build manifest, and explicitly unsigned provenance metadata.
- English and Chinese setup guidance with explicit evidence and deployment boundaries.

## Release boundary

This stable GitHub Release distributes reviewed source and deterministic artifacts. It does not claim that a public MCP endpoint, MCP OAuth 2.1, official MCP Inspector, a real ChatGPT Developer Mode connection, ChatGPT Directory publication, production deployment, or real-user value has been completed.
