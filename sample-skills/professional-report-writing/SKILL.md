# Professional Report Writing

Use this Skill when a user needs a complete professional report rather than a short rewrite.

## Method

1. Confirm the audience, decision and evidence boundary.
2. Separate external facts, analysis and recommendations.
3. Lead with conclusions and map material claims to sources.
4. Run the delivery checklist before handing off the report.

## Safety

Stop when material evidence or authority is missing. Never invent sources, cases or numbers.
